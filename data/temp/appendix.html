정상 이미지를 텍스트 조건으로 바꾸는 부분(image2prompt) 설정

  • 레퍼런스 논문: The CLIP Model is Secretly an Image-to-Prompt Converter (NeurIPS 2023) https://arxiv.org/abs/2305.12716 
  - OpenAI CLIP openai/clip-vit-large-patch14의 vision CLS embedding(1024차원)을 사용.
  - W_map = pinv(W_text) @ W_visual의 closed-form 변환을 적용.

  - negative prompt도 빈 문자열의 native SD embedding임.
  - Stable Diffusion 구조 자체는 변경하지 않았음.

마스크·해상도 설정

  - 원본 lesion mask를 grayscale로 읽고, dilation_px=9를 적용.

DDPM/UNet 및 diffusion 설정

  - 입력 crop: 224×224
  - UNet 조건 입력 3채널: [masked baseline, lesion mask, Gaussian noise channel]
  - 출력: 1채널 epsilon prediction
  - base channels 128, residual block 2, channel multiplier (1, 1, 2, 2, 4, 4)
  - attention: downsample rate 16
  - dropout 0, learned variance 비활성화, 총 파라미터 약 113.67M
  - 1,000 diffusion step, linear beta schedule (β=0.0001 → 0.02)
  - epsilon prediction, fixed-small variance, MSE loss, timestep rescaling 없음
  - 추론도 DDIM이 아니라 1,000-step DDPM reverse sampling p_sample_loop_known을 사용.
  - clip_denoised=True

Figshare 추론(훈련된 diffusion model로 음성 생성하는 단계) 시 전처리와 합성

  - grayscale 입력을 0.1–99.9 percentile clipping 후 [0,1] min–max 정규화합니다.

Natural Image (COD10K, MAS3K)

full dataset:

  • COD10K: https://huggingface.co/datasets/WOOJYE/COD10K/tree/main
  • MAS3K: https://huggingface.co/datasets/WOOJYE/gmpo_mas3k/tree/main

example (재윤) 

noise = N(μ=0, σ=50)       # RGB 채널별 독립 난수
negative = clip(original + noise, 0, 255)
  • 원시 Gaussian: μ ≈ 0, σ ≈ 50, 분산 ≈ 2500
  • alpha blending: 해당 없음. 원본에 대한 회귀 기울기가 0.85–0.97이며, clipping을 고려하면 additive 모델과 일치합니다.
  • 채널: 원시 RGB별 독립 noise입니다. 저장 JPEG의 4:2:0 chroma subsampling 때문에 파일을 직접 보면 채널 상관이 약 0.80–0.84로 높아 보입니다.
  • 공간 특성: 픽셀 독립 white noise. 잔차의 이웃 픽셀 상관은 0.05–0.15 수준으로 Gaussian blur 같은 공간 상관 노이즈가 아닙니다.
  • 적용 영역:
    • 폐: 파란 마스크
    • 심장: 초록 마스크
    • 기관지: 빨간 마스크
  • 마스크 내부에만 적용됐습니다. |Δ| ≥ 20 기준으로 마스크 밖 변화는 폐 0.3%, 심장 0.5%, 기관지 2.5%뿐이며, 모두 경계에서 4px 이내 JPEG DCT artifact입니다.
  • dilation/erosion/feathering: 확인되지 않았습니다. 실질적 경계는 hard boundary입니다.
  • clipping: [0, 255] uint8 clipping. 어두운 영역에서 평균 변화가 양수로 치우치고 분산이 작아지는 현상이 정확히 관찰됩니다.
  • 저장 형식: 512×512, 8-bit RGB JPEG, quality 95 수준의 양자화 테이블, 4:2:0 subsampling.
  • 모든 구조와 이미지에 동일한 noise strength가 적용된 것으로 보입니다. 100개 이미지를 대조했을 때 noise pattern 재사용 상관은 ~0이었습니다.

  1. T 와 T − k 생성하는 방법

평가용 텍스트 집합의 정의. AUROC/FPR 평가 CSV의 caption 열은 이미지별로 생성·샘플링한 설명문이 아니라, 클래스 라벨에 일대일로 대응하도록 사전에 고정한 짧은 문장이다. 클래스 집합을 C = {1, ..., K}, 클래스 k의 고정 문장을 tk라 하면, 평가 텍스트 집합은 T = {t1, ..., tK}이다. 이미지 픽셀, 이미지별 메타데이터(단, Figshare의 종양 유형 라벨 및 COD10K/MAS3K의 공식 클래스명은 제외), LLM, 난수는 캡션 선택에 사용하지 않았다. 같은 클래스의 모든 행은 완전히 같은 문자열을 사용한다.

T−k의 의미와 one-vs-rest. 이 문서에서 T−k = T \ {tk}는 표적 클래스 k를 제외한 나머지 클래스 문장 집합을 뜻한다. 실제 평가는 별도의 합성 “음성 프롬프트”를 만들어 T−k를 인코딩하지 않는다. 각 이미지 i에 대해 모든 tk와의 L2-정규화 코사인 유사도 si,k를 계산하고, yi(k) = 1[label(i)=k]로 이진화하여 k 대 나머지 모든 클래스의 AUROC 및 FPR@95%TPR을 구한다. 따라서 normal 또는 no camouflaged animal은 T−k의 대용물이 아니라, T 안의 독립적인 클래스 문장이다.

이 설계는 자연어로 시각 개념을 지칭해 zero-shot 전이를 수행하는 CLIP의 평가 관례와 일치한다. 다만 CLIP 원 논문은 아래의 정확한 문장을 규정하지 않았으며, 본 실험의 문장들은 재현성을 위해 프로젝트에서 고정한 템플릿이다. Radford et al., CLIP (2021)

라벨 원천: 200개 원본 영상과 각 해부학적 영역에만 Gaussian noise를 적용한 200개씩의 bronchus_noise, heart_noise, lung_noise 폴더명으로 클래스가 정해진다. 각 노이즈 클래스의 문장은 노이즈가 적용되지 않은 두 구조를 기술하고, 원본은 세 구조가 모두 보존되었다고 기술한다.

  • heart_noise → Chest CT image showing preserved bilateral lung aeration and patent central airways.
  • lung_noise → Chest CT image showing preserved cardiac contour and patent central tracheobronchial structures.
  • normal → Chest CT image showing preserved cardiac contour, preserved bilateral lung aeration, and patent central airways.

이 네 문장은 a1_inference/build_chest_ct_classwise_eval_csv.py의 CLASS_SPECS에 직접 지정했다. 기존 초안의 “GPT-5가 장기별 후보 문장을 10개 생성하고 매 영상마다 샘플링하였다”는 설명은 실제 평가 CSV와 일치하지 않으므로 적용하지 않는다. 이 평가에는 LLM 호출, 후보 풀, 이미지별 랜덤 샘플링이 없었다.

Natural images (COD10K and MAS3K)

라벨 원천: COD10K는 테스트 메타데이터의 69개 camouflage subclass와 no camouflaged animal, MAS3K는 33개 원본 객체 클래스와 같은 no-object 클래스를 사용한다. CAMOUFLAGED-object라는 문제 설정과 COD10K의 클래스 메타데이터는 Fan et al., COD10K (CVPR 2020)에 근거하지만, 아래 자연어 템플릿은 해당 논문이 제공한 문장이 아니라 본 평가에서 고정한 문장이다.

최종 scene-caption CSV에서의 고정 T: 원본 객체 행은 정규화한 클래스명 [class name]을 삽입해 정확히 There is an [class name] present in the scene.를 사용했다. no-object 행은 정확히 There is no camouflaged animal present in the scene.를 사용했다. 관사 an은 클래스명에 따라 교정하지 않고 모든 객체 클래스에 문자 그대로 유지했다.

평가 파일: COD10K는 data/COD10K/test/cod10k_original2026_no_object2026_subclass70_scene_caption_pairs_paths_fixed.csv (2,026 원본 + 2,026 no-object = 4,052행, 70클래스), MAS3K는 data/MAS3K/mas3k_original582_no_object582_classwise_scene_caption_pairs_paths_fixed.csv (582 원본 + 582 no-object = 1,164행, 34클래스)이다.

이전 manifest와의 구분: 경로 보정 이전의 *_caption_pairs_paths_fixed.csv에는 There is a [class name] hidden in the natural background. 및 There is no camouflaged animal hidden in the natural background. 템플릿이 남아 있다. 이는 이전 템플릿이며, 이름에 scene_caption이 있는 CSV로 산출한 결과와 혼용하지 않는다. 두 경우 모두 LLM 프롬프트나 이미지별 캡션 생성은 없으며, 공식 클래스명을 템플릿에 치환한 결정론적 문자열 생성이다.

재현 절차. 각 CSV 행에 image_path, class_label, caption을 기록하고, 평가 시 클래스별로 하나의 고유 캡션만 텍스트 인코더에 입력한다. 이어 clip4retrofit_ovr_metrics.py가 클래스별 one-vs-rest AUROC와 ROC 곡선에서 처음으로 TPR ≥ 0.95가 되는 지점의 FPR을 계산하고, 최종 macro 값은 클래스별 값을 동일 가중치로 산술평균한다. 따라서 캡션 생성 단계에는 seed, 온도, top-p, 모델 버전 같은 생성형 언어모델 하이퍼파라미터가 존재하지 않는다.

Chest CT

To construct the base captions for the chest CT dataset, GPT-5 was prompted with the following instruction:

"Generate ten distinct and medically accurate sentences describing the general anatomical, physiological, or functional characteristics of the lung, heart, and bronchus as they appear in chest CT images. Produce ten sentences for each organ. Each sentence should be concise, self-contained, and written in professional medical language. The descriptions should reflect general medical knowledge and must not refer to specific patients, diseases, abnormalities, imaging findings, or diagnostic interpretations. Ensure that the generated sentences are semantically diverse and suitable for use as generic captions for a chest CT vision-language dataset."

GPT-5 generated ten candidate sentences for each organ. For every chest CT image, one sentence was independently sampled from the lung, heart, and bronchus sentence pools, and the three selected sentences were concatenated to construct the base caption.
