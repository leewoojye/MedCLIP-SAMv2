4. **대혈관 (Vessels)** - 9.4% 🟡

6. **위 (Stomach)** - 2.1%

**핵심 문제**:

- **간이 FP의 26%** - 예상대로 큰 문제

- MedCLIP의 text prompt가 해부학적 위치를 충분히 고려하지 못함
- "pancreas" 텍스트만으로는 인접 장기를 배제하기 어려움

### 3. 췌장의 작은 크기와 불규칙한 형태
**췌장의 특성:**
- CT 슬라이스에서 상대적으로 작은 영역
- 머리-몸통-꼬리로 나뉘는 불규칙한 형태
- 주변 장기들에 둘러싸여 경계가 불명확

**모델의 약점:**
- 작은 영역보다 큰 영역에 더 높은 saliency 부여
- 불규칙한 형태를 일관되게 감지하지 못함

### 4. Zero-shot의 한계
**근본적 문제:**
- MedCLIP이 췌장을 학습할 때 다른 복부 장기와의 **상대적 관계**를 학습하지 못함
- "pancreas" 텍스트만으로는 **해부학적 맥락(anatomical context)**이 부족
- SAM은 saliency가 높은 영역을 선택하지만, 그것이 췌장인지 간인지 구별 불가

## 💡 개선 방안 제안

### 1. Text Prompt 개선 (실제 오인 분석 기반)
**현재**: "pancreas"  

**개선 (우선순위 순)**:
```
# 최우선: 신장과 간 배제
"pancreas only, exclude kidney and liver"

# 상세 버전
"pancreas only, not kidney, not liver, not duodenum"

# 해부학적 위치 강조
"pancreas in retroperitoneum, posterior to stomach, anterior to spine"

# 형태 강조
"elongated pancreas, pancreatic parenchyma"
```

### 2. Negative Prompt 추가 (실제 혼동 장기 기반)
**우선순위 1**: 신장 배제 (FP의 49%)
- "not kidney", "exclude renal tissue"

**우선순위 2**: 간 배제 (FP의 26%)
- "not liver", "exclude hepatic tissue"

**우선순위 3**: 기타 장기 배제
- "not duodenum", "not blood vessels"

### 3. 위치 기반 후처리 (공간적 제약)
**신장 영역 제거**:
- 우측 신장: 이미지 우측 (x > 0.55) 및 후복부 (y: 0.35-0.65) 영역 제거
- 좌측 신장: 이미지 좌측 (x < 0.35) 및 후복부 영역 제거

**간 영역 제거**:
- 이미지 우상부 (y < 0.35, x > 0.50) 영역 제거

**췌장 영역 제한**:
- 중앙부 (y: 0.35-0.55, x: 0.30-0.60)로 제한

### 4. Saliency Map 후처리
- **Top-K 제한**: 상위 K개 saliency 영역만 고려 (너무 넓은 영역 방지)
- **크기 제약**: 예측 영역이 이미지의 3%를 초과하면 재검토
- **형태 제약**: 췌장의 전형적인 형태(elongated)와 맞지 않으면 재조정

### 5. SAM Prompt 개선
- 현재 자동 포인트 대신 **중심부 영역만 선택**
- 여러 후보 중 **가장 compact한 영역** 선택
- 신장 및 간 영역의 포인트는 자동으로 제거

### 6. 앙상블 또는 후처리
- 과도하게 큰 예측은 **모폴로지 연산**으로 축소
- **연결 성분 분석**으로 여러 분리된 영역 중 가장 적절한 것만 선택
- 신장/간과 겹치는 영역은 자동 제거

### 7. Fine-tuning 고려
- 췌장 데이터셋으로 MedCLIP을 **few-shot fine-tuning**
- **특히 신장과의 구별력 향상에 집중**
- 대조 학습(contrastive learning)으로 췌장 vs 신장/간 구별
