🎨 색상 설명
================================================================================

오버레이 이미지에서:
  🔴 빨강 (255,0,0) = FP (False Positive)
      → 모델이 예측했지만 GT에는 없음
      → 모델의 과잉 예측 (오진)
      
  🔵 파랑 (0,0,255) = FN (False Negative)
      → GT에는 있지만 모델이 예측하지 못함
      → 모델이 병변을 놓침 (누락)
      
  🟢 초록 (0,255,0) = TP (True Positive)
      → 모델과 GT가 모두 일치
      → 올바른 예측
      
  검정 = TN (True Negative)
      → 모델과 GT 모두 음수
      → 정상 영역을 제대로 제외

================================================================================
📊 생성되는 통계 정보
================================================================================

콘솔 출력 예시:
  - 전체 TP, FP, FN, TN 개수
  - Precision (정밀도): TP / (TP + FP)
  - Recall (재현율): TP / (TP + FN)
  - F1-Score: 정밀도와 재현율의 조화평균
  - 상위 FP가 많은 이미지 (Top 5)
  - 상위 FN이 많은 이미지 (Top 5)

🆘 일반적인 문제 해결
================================================================================

Q: "ModuleNotFoundError: cv2" 에러
A: conda activate medclipsamv2 실행 후 다시 시도

Q: "파일을 찾을 수 없음" 에러
A: --gt-path, --pred-path, --image-path 값 확인

Q: 결과 이미지가 검은색
A: 마스크 파일 형식 확인 (0-255 범위의 바이너리)

Q: 메모리 부족 에러
A: 고해상도 이미지일 경우 이미지 리사이즈 필요

Q: 오버레이가 보이지 않음
A: --alpha 값을 0.5 이상으로 설정
